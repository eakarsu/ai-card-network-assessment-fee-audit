# Card Network Assessment Fee Audit

Recalculate card-network assessments and operating fees to recover misapplied volume, cross-border, and service charges.

**Primary buyer:** Merchants, acquirers, and payment facilitators. **Evidence:** network rulebooks, merchant categories, transaction volumes, domestic and cross-border attributes, assessments, switch fees, token fees, statements, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Network fee library
- Merchant hierarchy
- Transaction volume ingestion
- Domestic cross-border classification
- Assessment basis calculation
- Switch fee validation
- Token service fee audit
- Account updater fee audit
- Authorization fee control
- Chargeback fee validation
- Volume tier calculation
- Processor statement matching
- Credit request workflow
- Cash reconciliation
- Network merchant analytics

Run `./start.sh`, then open <http://127.0.0.1:4667>. API: `5667`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
